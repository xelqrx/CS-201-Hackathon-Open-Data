# Find A Car

Телеграм-бот пошуку машини по державних реєстрах України. Зроблено потужними людьми з KSE 

## Функціонал бота

- Меню 
- Моніторинг та обробка повідомлень
- пошук по номерному знаку/VIN машини
- Розшифровка VIN машини
- Можливість пошуку неїснуючого номерного знаку.

## Процес пошуку

1. Отримання VIN/Номерного знаку машини
2. Перевірка отриманих даних
2. Пошук у реєстрі за допомогою PostgreSQL
3. Розшифрування отриманих даних
4. Формування відповіді користувачу
5. Відправлення повідомлення

## Налаштування бази даних

Для пошуку задайте параметри PostgreSQL у `.env`:

```env
DB_HOST=localhost
DB_PORT=5432
DB_USER=your_user
DB_PASSWORD=your_password
DB_NAME=your_database
```

Встановіть залежності командою `pip install -r requirements.txt`.
